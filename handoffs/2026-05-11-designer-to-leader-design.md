# Handoff: NBA预测 H5 设计产出

## 1. 交付清单
- **设计说明**: `artifacts/design.md`
- **高保真原型**: `artifacts/react_native_mockups/index.html`
- **样式表**: `artifacts/react_native_mockups/styles.css`
- **交互脚本**: `artifacts/react_native_mockups/script.js`

## 2. 视觉设计核心 (High-Fidelity)
- **主题**: 采用高亮、通透的浅蓝色调 (#e0f2fe)，确保与头图 (hero-kv.jpg) 底部完美融合。
- **材质**: 全局应用微毛玻璃质感 (Glassmorphism)，卡片圆角 28px，背板模糊 20px。
- **适配**: 以 390px 为基准宽度，采用响应式布局，针对长文案（专家分析、规则）进行了行高与间距优化。

## 3. 关键状态实现
1. **默认态**: 选项未选，提交按钮禁用。
2. **选中态**: 点击“大/小”选项后高亮，激活提交。
3. **弹窗流转**: 
   - 提交 -> 弹出意愿询问 (磊哥看球/AI名称动态)
   - 愿意/不愿意 -> 弹出提交成功
   - 知道了 -> 页面转入“已提交”锁定态。
4. **异常处理**: 定义了 `.toast` 样式用于显示业务异常提示。

## 4. 后续开发建议
- **动态渲染**: 建议在渲染专家分析区时，根据 AB 实验组 ID 切换对应的 HTML 片段。
- **图片资源**: Mockup 中使用了占位图，正式开发请替换为正式的球队 Icon 与专家头像。
- **安全区**: CSS 中已包含 `env(safe-area-inset-top)` 处理，适配刘海屏。

## 5. 设计确认
设计已严格遵循 PRD 要求的“副标题：玩竞猜，送吧币”以及“不要做成深色体育页”的约束。
