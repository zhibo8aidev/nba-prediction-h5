# NBA预测 H5 设计说明文档

## 1. 视觉系统

### 1.1 色彩规范 (Color Palette)
- **品牌/主色**：`#3b82f6` (NBA 蓝/活动主色)
- **背景底色**：`#e0f2fe` (承接 KV 底部浅蓝色)
- **背景渐变**：`linear-gradient(to bottom, #e0f2fe, #f0f9ff)`
- **卡片底色**：`rgba(255, 255, 255, 0.4)` (微毛玻璃)
- **文字主色**：`#0f172a` (深蓝黑)
- **文字辅助色**：`#475569` (灰蓝)
- **高亮渐变**：`linear-gradient(135deg, #60a5fa 0%, #3b82f6 100%)` (提交按钮)

### 1.2 字体规范 (Typography)
- **页面标题**：18px, Bold, `#0f172a`
- **副标题/卡片标题**：15px, Semibold, `#0f172a`
- **正文文案**：14px, Normal, Line-height 1.6, `#475569`
- **标签/提示**：12px, Normal, `#64748b`

### 1.3 材质与阴影 (Material & Elevation)
- **玻璃材质**：`backdrop-filter: blur(20px); border: 1px solid rgba(255, 255, 255, 0.3);`
- **卡片阴影**：`0 12px 40px rgba(59, 130, 246, 0.1)`

## 2. 核心组件设计

### 2.1 头部 KV 适配
- **高度控制**：按 16:9 比例，390px 宽度下约为 219px。
- **融合处理**：图片底缘与 body 背景色对齐。
- **悬浮返回**：左上角 32px 圆形按钮，`backdrop-filter: blur(10px)`。

### 2.2 对阵卡片 (Match Card)
- **负边距**：`margin-top: -48px`
- **圆角**：28px
- **结构**：
  - Top: 截止时间
  - Middle: 球队 Icon + 名称 + "VS"
  - Bottom: 选项按钮组 + 提交按钮

### 2.3 分析卡片 (Analysis Card)
- **专家模块**：头像(40px) + 姓名 + 标签(准确度) + 长文案。
- **AI/球迷模块**：紧跟专家模块或单独卡片，头像(32px) + 角色标识 + 观点文案。
- **排版优化**：长文案行间距 1.6，段落间距 12px，确保在 390px 下不压抑。

### 2.4 弹窗系统 (Modals)
- **意愿弹窗**：居中，圆角 20px，背景白色半透明(0.95)，模糊背板。
- **成功弹窗**：文案较长，需居中对齐，按钮采用强调色。

## 3. 页面状态流转

### 3.1 默认态 (Default)
- 用户未选择选项，提交按钮置灰。
- 内容根据 AB 实验组动态展示。

### 3.2 选中态 (Selected)
- 点击“大”或“小”，按钮背景变为高亮蓝，文字反白。
- 提交按钮激活，变为渐变蓝。

### 3.3 提交中/已提交 (Submitted)
- 提交按钮显示 loading 或变为“已提交”置灰态。
- 选项按钮锁定，不可再次点击。

### 3.4 异常态 (Error)
- 网络异常或数据缺失时，展示 Toast 提示或全屏兜底图。

## 4. 实验组适配 (AB Testing)
- **Baseline**: 仅专家。
- **Information**: 专家 + 战绩标签。
- **AI**: 专家 + AI 角色与观点。
- **Comment**: 专家 + 球迷角色与观点。
- **Control**: 仅保留对阵与选项。
