# NBA预测 H5 视觉与交互设计规范

> 来源：2026-05-11 Feishu 群聊，用户直接提供。
> 备注：文档中提及已落地 `NBA_Prediction.html` 原型，但当前会话未附上该 HTML 文件，本项目先按文字规范归档。

## 1. 全局视觉架构 (Global Visual Architecture)
- **全面屏沉浸式**
  - 取消页面顶部的实色/毛玻璃导航栏，使头部视觉（KV）直接从屏幕最上沿 `top: 0` 起渲染。
  - 顶部仅保留绝对定位的悬浮返回按钮，位于左上角，需适配刘海屏安全区 `env(safe-area-inset-top)`。
  - 返回按钮采用 `32x32px` 圆形毛玻璃背景。
- **头图（Key Visual）标准**
  - 比例通常采用 `16:9`，宽度必须 `100%` 铺满移动端容器（最大 `480px`）。
  - 容器底部要求 `font-size: 0`，彻底消除图片缩放导致的 `1px` 底部间隙。

## 2. 色彩空间与融合 (Color & Blending)
- **高亮影棚调性**：全局必须保持通透、明亮，严禁使用单调死板的深色或纯黑背景。
- **全域底色同步定律**
  - 页面的全局底色（`body` 及 `app-container`）必须精准吸取 KV 图像最底部的浅色，当前为浅动感蓝 `#e0f2fe`。
  - 目标是实现头图与页面背景的无缝融合，让下方内容卡片仿佛漂浮在同一片空间之上。
- **深色文本**
  - 主文本：`#0f172a`
  - 辅助文本：`#475569`

## 3. 组件材质与布局 (Component Structure & Glassmorphism)
- **空间纵深与层叠**
  - 页面内第一张卡片（对阵卡片）必须设置负边距 `margin-top: -48px`，优雅地覆盖在头图下半部分。
- **微毛玻璃质感**
  - 卡片底色：`rgba(255, 255, 255, 0.4)`
  - 卡片描边：`rgba(255, 255, 255, 0.3)`
  - 背板模糊：`backdrop-filter: blur(20px)`
  - 卡片阴影：`0 12px 40px rgba(59, 130, 246, 0.1)`

## 4. 元素与组件精密尺寸 (Element Metrics)
### 赛程卡片 (Matchup Card)
- 外边距：左右 `16px`，底部卡片间隙 `16px`
- 内边距：上下 `16px`，左右 `20px`
- 圆角：`28px`

### 球队展示区 (Team Display)
- 截止时间：左对齐，字号 `13px`，颜色 `text-muted`，距离下方元素 `margin-bottom: 16px`
- 球队图标：`48x48px` 正圆形，外加 `2px` 白色半透明描边和淡蓝阴影
- 球队名称：字号 `14px`，`font-weight: 600`
- VS 标志：字号 `24px`，加粗斜体

### 竞猜按钮选项区 (Options)
- 选项按钮：字号 `13px`，内边距 `12px 10px`，圆角 `12px`
- 未选中背景：浅白透明
- 选中背景：主题蓝 `#3b82f6`，字体反白
- 提交按钮：字号 `15px`，内边距 `12px`，全圆角 `border-radius: 24px`
- 提交按钮背景：蓝紫高亮渐变

### 弹窗组件 (Modals)
- 采用浅色主题 `rgba(255, 255, 255, 0.95)`
- 圆角 `20px`
- 背板模糊
- 整体轻盈灵动，弱化压迫感
